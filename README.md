  1. Using the GitHub Web Interface to access and launch the project

- Navigate to the repository on https://github.com/Eno236/BlusaltA
- Browse through the repository's file structure to find the file you want (i.e cypress)
- Click on the code dropdown button and click on "Download Zip" to download a copy of the file:
- Extract the zip file to access the cypress folder
- open vscode
- go to file and click on open folder, select cypress folder to launch the project

  2. How to run the test
  - Navigate to terminal and click new terminal
  - Type the following command to open cypress 'npx cyress open'
  - Cypres loads,click on E2E testing
  - chose chrome  and click on E2E testing to view landing page.
  - click project "Registration-login" all the spec will be list
  - chose login and run
